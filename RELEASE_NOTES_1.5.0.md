# SteamGridBox 1.5.0

- Added a public shared artwork browser for BOXROOM addons.
- SteamGridBox now centrally owns SteamGridDB credentials, searching, artwork categories, downloads, previews, loading state, cancellation, and errors.
- Added portrait, square, wide, hero, and transparent-logo selection using actual returned dimensions.
- Fixed logo requests to use SteamGridDB's supported PNG filter.
